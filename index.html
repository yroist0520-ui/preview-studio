Features

一个工具，搞定预览图全部细节

从背景到文字、从作品图到撕纸纹理，每一项都为你调好。

✦

字稿风模式

图片铺满画布 + 冷调滤镜 + 底部信息栏 + 头像署名 + 四角星装饰，一键还原字稿圈美学。

智能取色渐变

上下羽化蒙版

作品图上方 / 下方 / 上下双羽化，羽化宽度可调，柔和过渡到背景。

先选择一种预览风格，进入对应工作区。所有操作即时渲染，左边调参，右边看效果。

普通作品预览

方形 / 竖版画布，背景 + 作品图 + 描边投影 + 手写英文标题，最经典的作品展示方式。

字稿风预览

图片铺满 + 暖金叠加 + 信息栏 + 头像署名 + 四角星，一键还原字稿圈美学。

拍立得预览

个人主页模板

仿社交平台个人主页：状态栏 + 大图背景 + 白色信息卡（圆形头像、昵称、在线状态、粉丝/关注/转评赞统计）+ 个性签名，所有元素可拖拽可显隐。

个人主页预览

仿社交平台个人主页：顶部背景图（上传 / 移动 / 缩放 / 模糊 / 透明度）+ 交界处悬浮头像 + 昵称简介 + 日期 / 图片 / 正文三列动态流，全部元素可点选编辑、画布拖动，支持预设与全屏水印导出。

相框风预览

同一张作品图放大模糊铺满背景，中央清晰展示原图；四角白色 L 形角标 + 顶部小条 + 底部指示条，画框缩放、圆角、角标长度与粗细、模糊与薄纱全部可调。

作品展示轴

一次上传多张作品，横向铺成一条展轴：中间最大、两侧递减，垂直错落叠压，白底柔和投影，长横幅画布适合系列作品陈列。

自由拼图

多张图片任意排列成网格拼图，自由设置行列数、间距、圆角、边框，支持等宽/等高等比铺满，图片清晰不模糊。

杂志手账

秋日摄影长图：顶部诗句封面 + 中部米白双页线圈手账 + 底部英文主题页，独立杂志与摄影手账气质。

壁纸＋方图双模板

左侧手机壁纸、右侧方形商品图双画布实时预览，元素自由拖拽缩放、头像上传、白色信息栏独立编辑，支持高清 PNG 导出。

How it works

四步出图

从打开页面到导出 PNG，全流程不超过 30 秒。

1

选尺寸 / 一键字稿风

选 12 种画布尺寸任一，或直接点「一键应用字稿风预设」自动配好全部参数。

2

上传作品 + 智能取色

「⑤」上传主图后点「从图片提取主色」，背景渐变自动跟随图片色调。

3

调字稿风细节

开字稿风模式，上传头像、填署名、调四角星 / 竖排英文 / 底部信息栏。

4

存预设并导出

满意后点「存到 1」留档（各模板独立），再点「导出 PNG」即下载，手机平板电脑全兼容。

准备好了吗？

所有渲染在浏览器本地完成，不上传任何图片，安全又快速。手机、平板、电脑均可使用。
